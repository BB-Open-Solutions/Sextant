# Roadmap after 1.0

with the trigger that forces each item rather than a wish list.

[`docs/roadmap.md`](https://github.com/BB-Open-Solutions/Sextant/blob/main/docs/roadmap.md),
next to the decision records and the scale measurements it refers to, so a
